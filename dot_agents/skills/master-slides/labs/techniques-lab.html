Techniques lab · three new rendering paths

Three visual techniques I haven't used yet.

All my existing graphics are CSS transforms + SVG paths + CSS keyframes. These three each open a fundamentally different rendering path — particle physics, declarative filter effects, and chromatic blend-mode compositing. Pick one to integrate into the toolkit and whole families of new visuals unlock.

Technique 01
Canvas flow field
Canvas 2D · particle sim · noise field
200 particles moving through a sine-wave vector field. Each particle has position, velocity, and age. Every frame I sample the field direction at its location and nudge it along. Trails come from not fully clearing the canvas each frame — leaving a subtle orange afterglow.
unlocksthought flow, context streaming, data ingestion at scale, ambient backgrounds for hero slides, "the system is alive." Any concept where you want many things moving at once.
Technique 02
SVG filter warp
SVG · feTurbulence + feDisplacementMap · animate
Declarative noise + displacement. A turbulence pattern (fractal noise) distorts anything routed through the filter — text, shapes, entire groups. Animating the displacement scale makes the distortion breathe. Zero JS.
unlocksinterpretation, hallucination, context drift, "what the agent sees," heat shimmer, water surface, unsettled states. Anything where clarity wavers.
Technique 03
Conic + blend modes
CSS · conic-gradient · @property --angle · mix-blend-mode: screen
Three conic gradients stacked with mix-blend-mode: screen so their colors add chromatically. Each spins at a different rate using @property --angle for smooth custom-property animation. The overlap produces colors none of the layers contain on their own.
unlocksmulti-model orchestration, synthesis, harmony, "when three things align," multi-agent chorus, consensus. Anything where separate things combine into something new.
Technique 04
Mask-image wipe
reveal
gradient mask · linear wipe
CSS · mask-image · gradient position animation
A linear-gradient mask wipes across the element — hard edge, not an opacity fade. The mask is oversized and its position animates, so content appears and disappears with a clean edge. Works on text, SVG, images, anything.
unlocksreveals, curtain openings, "what's behind this," progressive disclosure, before-after wipes. Different from opacity in that the transition is a hard edge — feels like a scanner or a flashlight beam.
Technique 05
Motion path
CSS · offset-path · offset-distance
Elements travel along an arbitrary SVG path via offset-path: path(...). Animate offset-distance from 0% to 100% and the element follows the curve — including orientation if you want. Three dots at different delays = a flowing pipeline.
unlockschoreographed motion, traffic along routes, execution traces, particle along curve, "data flows from A to B via C." Precise curved motion you can't get from standard keyframes alone.
Technique 06
Clip-path morph
CSS · clip-path polygon · keyframe interpolation
A single element (with a conic-gradient fill for color shift) cycles through shapes — diamond, hex, triangle, square, star — by animating the clip-path: polygon() coordinates. The browser interpolates between polygon point-sets if they have the same number of points.
unlocksshape transformation, state changes, "what form does the agent take," identity morph, mode-shift visualizations. Strong primal feel — we read shape change as state change.
Technique 07
Canvas pixel glitch
Canvas 2D · getImageData / putImageData · RGB channel shift
Draw a stable base (text, shape) to canvas, then periodically grab the pixel buffer and mess with it: shift scanlines horizontally, offset the red channel, drop random static. Feels like a CRT being hit by interference. Pure pixel manipulation, no filters.
unlocksuncertainty, error states, "signal lost," CRT/retro aesthetic, corrupted data, glitch transitions. Adds an edge that clean vector graphics can't reach.

CSS · backdrop-filter: blur + saturate · alpha panels
Semi-transparent panels with backdrop-filter: blur() sit on top of a noisy radial-gradient background. The blur only applies to what's behind each panel — the colors bleed through as soft light. Boosts saturation to preserve color vividness through the blur.
unlocksdepth layering, floating dashboards over busy scenes, HUD overlays, "looking through to what's underneath," apple-style product aesthetics. Creates visual hierarchy via depth rather than color.
Technique 09
Kinetic type
agentic
CSS · per-letter transform · staggered animation-delay · color cycling
Each letter is its own span. Keyframes shift translateY + rotate + color per letter, with staggered delays so the effect cascades across the word. Uses the full palette — orange / cyan / violet — cycling letter by letter.
unlockstext as material, hero title moments, emotional beats, "the word itself is alive," editorial drama. Different from static type: words become performances.

CSS · perspective · translateZ · rotateY on parent
Three layers at different translateZ distances sit inside a preserve-3d parent that slowly rotates on Y-axis. Far layer (-120px) moves slower visually than near layer (+120px) — true parallax from perspective projection. No image tricks.
unlocksspatial depth, layer hierarchy visualized, "things in front / behind," narrative depth (foreground = active, background = context), abstract stage sets. Feels like a real scene, not a flat graphic.
Why three and not ten: each one is a whole new rendering surface. Canvas opens particle physics and generative art. SVG filters open declarative distortion and noise effects. Conic + blend modes open chromatic compositing with zero images. Adopting one adds hundreds of potential visuals. Adopting all three = we can paint nearly anything.

How to use: tell me the number and the concept. Examples: T01 for M3 context streaming (ambient background of every iso slide), T02 for stochastic / drift concept in M2, T03 for M5 multi-model orchestration (hero graphic).
